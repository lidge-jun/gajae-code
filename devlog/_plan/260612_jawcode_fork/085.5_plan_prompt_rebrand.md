## 0. 핵심 판정 3가지

1. **표시 갭**: `prompts/*.md`는 `with {type:"text"}` 빌드타임 임베드인데 `buildSystemPrompt`의 `data`(`system-prompt.ts:593-619`)에 `APP_NAME`이 없음 — jwc 실행에서도 "You are GJC, the Gajae Code coding agent"(`system-prompt.md:3`)가 그대로 나간다.
2. **기능 버그 (표시 문제 아님·최우선)**: role-agent(planner/architect/critic)의 restricted bash allowlist가 `gjc ralplan --write`/`gjc state` 접두어로 고정(`prompts/agents/planner.md:7-8` frontmatter, `bash-allowed-prefixes.ts:122` `words[0] !== "gjc"`). **jwc 단독 설치에서는**: 프롬프트대로 `gjc state` 실행 → bin 부재로 실패 / 올바른 `jwc state` 실행 → allowlist가 거부. mutation-guard의 `/^gjc(?:\s|$)/`(`jaw-interview-mutation-guard.ts:254`)도 jwc 명령을 인식 못 해 우회/차단 불일치. (skill 체인 handoff는 in-process라 무사 — `tools/skill.ts:120`)
3. **스킬 본문 직접 수정 불가**: `default-gjc-definitions.test.ts:343-354`가 gjc 스킬 본문에 `jwc interview` 등 jaw 어휘를 **명시 금지**, `:357-371`은 `gjc ralplan --write …` 문구를 **필수 요구**. rebrand/G002는 번들 4종 디렉터리 invariant 고정. → 전환은 소스가 아니라 **런타임 치환 레이어**로만 가능.

## 2. 전환 설계 [기본값]

**3레이어 조합** (직원 비교: ① 로드 후 치환 / ② md 2벌 / ③ placeholder — ②는 drift 비용으로 기각):

| 레이어 | 대상 | 방법 |
|--------|------|------|
| **L1. handlebars data 확장** | `system-prompt.md`, `bash.md` 등 `prompt.render` 경유 템플릿 | `buildSystemPrompt` `data`에 `APP_NAME`/`APP_NAME_UPPER`/`ENGINE_NAME` 추가 + md에 `{{APP_NAME}}` 플레이스홀더 삽입 — **gjc 실행 시 동일 출력**(APP_NAME=gjc)이라 diff-0 |
| **L2. `brandPromptText()` 순수 헬퍼** | agents md(`task/agents.ts:43-45` render 지점), orchestrate jaw md, 에러/안내 문자열 | 경계-안전 치환: `.gjc/`·`GJC_*`·`@gajae-code`·`defaults/gjc/` **보존**, 단어 경계의 `gjc `(명령 접두)·"GJC "(산문)만 APP_NAME으로. jwc=jaw 브랜드일 때만 작동, gjc 브랜드는 no-op |
| **L3. 스킬 본문 런타임 치환** | 번들 4종 SKILL.md | **`buildSkillPromptMessage()`(`extensibility/skills.ts:398-410`)에서만** 본문 치환, 설명은 `resolveSkillSlashCommands()`(`:379-395`)+`getEmbeddedDefaultGjcSkills()` fallback. 소스 파일 무수정 → 가드 전부 green 유지 |

**기능 버그 수정 (표시와 분리된 M1):**

- `bash-allowed-prefixes.ts:122`: `words[0] !== "gjc"` → **dual-prefix** `!== ENGINE_NAME && !== APP_NAME` (gjc·jwc 모두 허용 — 스킬 본문이 `gjc …`를 지시해도, 치환된 본문이 `jwc …`를 지시해도 동작)
- agents frontmatter `bashAllowedPrefixes`: 정적 문자열 → `task/agents.ts`에서 APP_NAME 변형도 함께 등록 (런타임 생성)
- `jaw-interview-mutation-guard.ts:254` `/^gjc(?:\s|$)/` → ENGINE_NAME|APP_NAME 양쪽 인식 (우회/차단 일관성)
- 검증: jwc-only PATH 환경에서 planner spawn → `jwc state read` 허용 + `jwc ralplan --write` 동작 테스트
