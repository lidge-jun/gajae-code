### deferred (허용 목록대로)
- TUI-only Bun API (bun:ffi) — lazy-throw 별칭, 호출부 try/catch (Node SDK graph 무관)

- archive write/extract 엣지(sparse·100B+ 이름) — 명시 에러

- `Bun.randomUUIDv7`(RFC 9562)·`Bun.plugin` no-op·`Bun.stringWidth`·`resolveSync` 보강

## deferred 허용 목록

100 closeout에서 deferred로 남길 수 있는 항목:

| 항목 | 조건 |
|------|------|
| TUI-only Bun API | Node SDK graph에 포함되지 않음 |
| STT/pty 경로 | M2 resident engine 필수 경로 아님 |
| auth-broker/gateway full server | 실 provider SDK hello world에 불필요 |
| archive write edge cases | read/write 핵심 도구가 Node import를 막지 않음 |

허용되지 않는 deferred:

- `createAgentSession` import 실패
- provider credential load 실패가 코드 원인인 경우
- stream parser 실패
- prompt/defaults 로드 실패
- Bun TUI 경로 회귀

## 110 handoff 계약

100 완료 후 110에 넘기는 계약:

```text
import { createAgentSession } from "jwc/sdk"  // cli-jaw에서 단일 import
```

110은 내부 `@gajae-code/*`를 직접 import하지 않는다. cli-jaw 측은 `packages/jwc/dist-node/sdk.js` 또는 package export를 통해 SDK만 사용한다.

## 최종 검증 커맨드

```bash
bun run check:ts
bun run check:jwc-ui
bun --cwd=packages/jwc run build:node
node -e "import('./packages/jwc/dist-node/sdk.js').then(m => { if (!m.createAgentSession) throw new Error('missing createAgentSession'); console.log('ok'); })"
```

실 provider smoke는 credential 상태에 따라 별도 실행 로그를 남긴다.
