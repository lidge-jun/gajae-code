### A안 (권장, 레퍼런스 일치): 선행 Spacer 조건부(첫 블록 0) + 내부 패딩 0

- 위험: 도구↔직전 텍스트 경계가 붙어 보일 수 있음 → 조건부 1줄로 경계만 유지.

  (`packages/tui/src/components/box.ts`) 확인 후 가로/세로 패딩 인자 분리 적용.
