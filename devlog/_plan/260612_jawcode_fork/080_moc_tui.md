# 080 MOC — TUI 변경 (jaw 테마 + 워크플로 시각화)

> 상태: ⬜. 입력: 사용자 "주력으로 개발할 TUI 필요" [확정], 040–060 산출물이 표시 대상이라 그 뒤에 배치.

## 코드 사실

- `packages/tui/` — 자체 차등 렌더링 라이브러리 (editor/autocomplete/keybindings/components)
- `packages/coding-agent/src/modes/interactive-mode.ts` — TUI 모드 진입점
- TUI는 Bun 전용 7파일 — **Node 포팅 대상 아님** (D8: 서버 임베딩은 비TUI 경로만)

## 스코프

1. jaw 브랜딩 테마: 배너/컬러/심볼 (010 brand.ts 상수 소비)
2. 인터뷰 위젯: 4차원 점수 + ambiguity 게이지 라운드별 표시 (040 산출)
3. PABCD 단계 인디케이터: 현재 단계/게이트 상태 상시 표시 (050 산출)
4. goal 상태 표시: active goal/checkpoint 진행 (060 산출)
5. 한국어 UX: 입력기(IME) 경계 케이스, 한글 폭 계산 검증

## [기본값] 결정

- 업스트림 TUI 컴포넌트는 재사용, jaw 위젯은 신규 컴포넌트로 추가 (기존 컴포넌트 최소 수정)
- 키바인딩 기본값 업스트림 유지, jaw 전용은 충돌 없는 범위에서 추가
- 스킨 수준을 넘는 레이아웃 개편은 별도 밴드로 미룸 (M1은 표시 항목 추가까지)

## 완료 기준

- TUI에서 인터뷰 차원 점수·PABCD 단계·goal 상태가 시각 표시
- 한글 입력/표시 스모크 (폭/IME)
- jaw 테마 스크린샷을 본 밴드 문서에 기록

## 열린 질문

- 위젯 배치(상태바 vs 사이드 패널) — 착수 시 목업으로 결정
- jwc TUI에서 cli-jaw 서버 상태 표시(읽기 전용 헬스)를 넣을지 — [기본값] M1 범위 밖
